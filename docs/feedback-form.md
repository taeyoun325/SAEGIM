# 새김 — 테스터 피드백 구글 폼

비공개 테스트(Closed testing) 참여자에게 보낼 피드백 폼 원고입니다.
`scripts/create-feedback-form.gs`를 쓰면 이 내용 그대로 폼이 자동 생성됩니다.

## 폼 설정

| 항목 | 값 |
|---|---|
| 제목 | 새김 테스트 피드백 |
| 설명 | 아래 "폼 설명" 참고 |
| 이메일 주소 수집 | **끄기** (익명 응답 — 솔직한 의견을 받기 위함) |
| 응답 1회로 제한 | 끄기 (구글 로그인 강제하지 않음) |
| 진행률 표시줄 | 켜기 |
| 응답 후 메시지 | 소중한 의견 감사합니다! 새김을 더 낫게 만드는 데 쓰겠습니다. 🌱 |

### 폼 설명

```
새김을 테스트해 주셔서 감사합니다.

3분이면 충분합니다. 솔직할수록 도움이 됩니다 — 좋았던 점보다
불편했던 점이 훨씬 값집니다. 익명이라 이름은 남지 않습니다.

문의: saegimsemi@gmail.com
```

## 1부. 어떻게 사용하셨나요

**1. 어떤 환경에서 사용하셨나요?** (객관식 · 필수)
- 안드로이드 폰 (Play 스토어 설치)
- 안드로이드 태블릿
- 웹 브라우저 (saegim.web.app)
- 기타

**2. 며칠 정도 써보셨나요?** (객관식 · 필수)
- 오늘 처음 써봤어요
- 2~3일
- 4~7일
- 일주일 이상

**3. 하루에 보통 몇 번 열어보셨나요?** (객관식)
- 거의 안 열었어요
- 하루 1번
- 하루 2~3번
- 그보다 자주

## 2부. 사용 경험

**4. 전반적으로 얼마나 만족하셨나요?** (선형 배율 1~5 · 필수)
`1 = 별로예요` / `5 = 아주 좋아요`

**5. 앱을 처음 켰을 때, 무엇을 하는 앱인지 바로 이해되었나요?** (객관식 · 필수)
- 바로 이해했어요
- 좀 헤맸지만 금방 알았어요
- 뭘 해야 할지 몰랐어요

**6. "오늘의 글감으로 3줄 쓰기"라는 흐름이 자연스러웠나요?** (선형 배율 1~5)
`1 = 부담스러웠어요` / `5 = 딱 좋았어요`

**7. 마음에 든 기능을 모두 골라주세요.** (체크박스)
- 매일 하나씩 도착하는 글감
- 스티커를 떼면 글감이 보이는 연출
- 3줄 제한
- 다른 사람들의 생각을 보는 피드
- 좋아요 / 댓글
- 캘린더로 지난 기록 돌아보기
- 연속 새김(스트릭)
- 프로필 통계
- 나만 보기 / 공개 전환
- 기타

**8. 불편하거나 아쉬웠던 부분을 모두 골라주세요.** (체크박스)
- 위와 동일한 보기 + `딱히 없었어요` / `기타`

**9. 8번에서 고른 항목, 구체적으로 어떤 점이 불편했나요?** (장문형)

## 3부. 오류 신고

**10. 오류나 이상한 동작을 겪으셨나요?** (객관식 · 필수)
- 아니요, 없었어요
- 네, 있었어요

**11. (있었다면) 어떤 상황에서 무슨 일이 있었나요?** (장문형)
> 도움말: 어느 화면에서, 무엇을 눌렀을 때, 어떻게 됐는지 적어주시면 큰 도움이 됩니다.

**12. 앱이 느리거나 멈춘 적이 있나요?** (객관식)
- 없었어요 / 가끔 그랬어요 / 자주 그랬어요

**13. 화면 사진이 있다면 올려주세요.** (파일 업로드 · 선택)
> ⚠️ 파일 업로드 문항은 구글 로그인이 필요해 익명 응답이 깨집니다.
> 익명성을 우선한다면 이 문항은 빼고, 스크린샷은 메일로 받으세요.
> (스크립트에서 `INCLUDE_FILE_UPLOAD = false`가 기본값)

## 만드는 법

1. https://script.google.com → 새 프로젝트
2. `scripts/create-feedback-form.gs` 내용을 붙여넣기
3. `createSaegimFeedbackForm` 함수 선택 후 실행 (첫 실행 시 권한 승인)
4. 실행 로그에 뜨는 **공개 링크(published URL)** 를 테스터에게 전달
