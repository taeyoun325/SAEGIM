## 1. 앱 세부정보

### 앱 이름 (30자 이내)
```
새김 - 오늘의 생각을 새기다
```

### 간단한 설명 (80자 이내)
```
매일 하나의 글감, 나만의 3줄. 같은 글감을 본 사람들의 생각을 함께 읽어보세요.
```

### 자세한 설명 (4000자 이내)
```
매일 같은 글감으로 함께 쓰는 3줄 기록, 새김입니다.

■ 매일 하나의 글감
모든 사용자가 같은 날 같은 글감을 받습니다. '우정', '10년 후의 나',
'행복이란 무엇일까?' 같은 글감 하나가 매일 도착합니다.

■ 나만의 3줄
길게 쓰지 않아도 됩니다. 떠오른 생각을 두세 줄로 짧게 새기면 충분합니다.
글쓰기가 부담스럽지 않도록 딱 3줄만 준비했습니다.

■ 나만 보기, 또는 함께 나누기
새긴 생각은 기본적으로 나만 볼 수 있습니다. 마음이 움직일 때만 공개하세요.
공개한 글은 언제든 다시 비공개로 바꿀 수 있습니다.

■ 같은 날, 다른 생각들
"오늘 다른 사람들은 이 글감을 어떻게 생각했을까?"
같은 글감을 본 사람들이 새긴 생각을 함께 읽을 수 있습니다.
마음에 드는 글에 좋아요와 댓글을 남겨보세요.

■ 캘린더로 돌아보기
내가 어떤 날 어떤 생각을 새겼는지 캘린더에서 한눈에 볼 수 있습니다.
그날의 인기 글도 함께 확인할 수 있습니다.

■ 연속 새김
매일 기록하면 연속 일수가 쌓입니다. 하루 놓쳐도 괜찮습니다.
부담이 아니라 작은 즐거움이 되도록 만들었습니다.

■ 안심하고 쓸 수 있도록
- 부적절한 글과 댓글을 신고할 수 있습니다
- 보고 싶지 않은 사용자를 차단할 수 있습니다
- 이름, 전화번호, 주소 같은 개인정보는 수집하지 않습니다
- 계정을 삭제하면 새긴 글과 댓글이 모두 함께 삭제됩니다

오늘의 생각을 새겨보세요.
```

## 2. 그래픽 자료

| 항목 | 파일 | 규격 |
|---|---|---|
| 앱 아이콘 | `store-assets/play-icon-512.png` | 512×512 ✅ |
| 그래픽 이미지 | `store-assets/feature-graphic.png` | 1024×500 ✅ |
| 스크린샷 | `store-assets/screenshots/` (5장) | 최소 2장, 세로 ✅ |

> 아이콘·그래픽은 `node scripts/generate-store-assets.js`로 다시 만들 수 있어 저장소에
> 넣지 않는다. 스크린샷은 실기기에서 직접 찍은 것이라 재생성이 불가능해 저장소에 포함한다.

### 스크린샷 촬영 방법 (실기기)
Expo Go로 앱을 실행한 상태에서 폰 화면을 캡처하세요. 아래 5장을 추천합니다.

1. **오늘** — 캐릭터 스티커가 글감을 덮고 있는 상태
2. **오늘** — 스티커를 떼고 글감이 보이며 3줄 입력한 상태
3. **피드** — 다른 사람들이 새긴 생각 목록
4. **캘린더** — 날짜에 점이 찍힌 모습
5. **프로필** — 통계와 공개한 생각

> Play는 세로 스크린샷 최소 2장을 요구합니다(320~3840px). 폰 기본 캡처면 규격에 맞습니다.

## 4. 데이터 안전(Data safety) 설문 답변

Play Console → 앱 콘텐츠 → 데이터 안전에서 아래대로 답하세요.

### 데이터를 수집하거나 공유하나요?
**예** (수집함, 제3자와 공유하지 않음)

### 전송 중 데이터 암호화
**예** (Firebase는 HTTPS/TLS 사용)

### 사용자가 데이터 삭제를 요청할 수 있나요?
**예** — 앱 내 [설정 → 계정 삭제]에서 직접 삭제 가능

### 수집하는 데이터 유형

| 카테고리 | 데이터 유형 | 수집 | 공유 | 필수 | 목적 |
|---|---|---|---|---|---|
| 개인정보 | 이메일 주소 | 예 | 아니요 | 필수 | 계정 관리, 인증 |
| 개인정보 | 사용자 ID (닉네임) | 예 | 아니요 | 필수 | 계정 관리, 앱 기능 |
| 앱 활동 | 앱 내 검색어 외 기타 사용자 생성 콘텐츠 | 예 | 아니요 | 필수 | 앱 기능 |

> **주의**: 아래 항목은 **수집하지 않음**으로 답하세요.
> 위치, 금융정보, 연락처, 사진/동영상, 오디오, 파일, 캘린더,
> 기기 ID, 광고 ID, 결제 정보, 건강 정보, 이름, 전화번호, 주소, 생년월일

### 사용자 생성 콘텐츠 세부
- 콘텐츠 유형: **기타 사용자 생성 콘텐츠** (글, 댓글)
- 목적: **앱 기능**
- 필수 여부: **필수**

- **13~15세 이상** 선택 (UGC 앱이므로 아동 대상 앱으로 분류하지 않음)
- "아동을 주 대상으로 하는 앱입니까?" → **아니요**

> ⚠️ 개인정보처리방침에는 "만 14세 미만을 대상으로 하지 않는다"고 적혀 있습니다.
> Play의 연령 구간은 13-15세부터라 그대로 골라도 반려 사유는 아니지만,
> 방침 문구를 "13세 미만"으로 맞추거나 가입 시 14세 이상 확인을 넣으면 더 깔끔합니다.

## 9. 출시 경로 — 비공개 테스트가 먼저입니다 ⚠️

Play 개발자 계정이 **2023년 11월 이후 만들어진 개인 계정**이라,
구글 정책상 **프로덕션 출시 신청 전에 비공개 테스트를 먼저 통과**해야 합니다.

| 요건 | 내용 |
|---|---|
| 트랙 | 비공개 테스트(Closed testing) |
| 테스터 수 | **12명 이상**이 계속 옵트인 상태를 유지 |
| 기간 | **연속 14일** |
| 이후 | Play Console에 "프로덕션 출시 신청" 버튼이 열림 |

즉 오늘 하는 일은 **비공개 테스트 트랙에 AAB 업로드 + 스토어 등록정보/설문 작성**까지입니다.
프로덕션 검토 제출은 14일 뒤에 가능합니다.

### 테스터 모으기
- Play Console → 테스트 → 비공개 테스트 → 테스터 → 이메일 목록 생성
- 테스터의 **구글 계정 이메일**이 필요합니다 (12명 이상, 여유 있게 15명 권장)
- 각자 옵트인 링크로 들어가 설치까지 해야 인정됩니다
